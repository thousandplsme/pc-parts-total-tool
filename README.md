# 自作PC買取 パーツ合算ツール

公開URL：[パーツ合算ツールを開く](https://thousandplsme.github.io/pc-parts-total-tool/)

GitHub Pagesで公開済みです。スマートフォン・PCのブラウザーから利用できます。

パーツごとの売価を手入力して合算し、編集可能な掛けで計算した「買取目安（参考値）」を確認する、日本語の査定補助ツールです。

**合算は売価の合計であり、査定額そのものではありません。最終判断は人が行います。**

## ローカルで使う

画面最上部の4タブでモードを切り替えます。既定は「パーツから入れる」です。「メモから作る」は取り込み専用、「パーツから入れる」はパーツ行・掛け・査定メモ、「PC査定のポイント」と「互換性チェック」はそれぞれ独立した内容だけを表示します。切替後も入力内容は保持し、通常のタブ切替はページの先頭から始まります。合算の固定バーは査定系2モードでだけ画面下部に表示します。タブは左右矢印キー・Home・Endでも切替可能です。

パーツ行の通常表示は種別・型番・採用価格・次のサイトを開くの4要素です。状態、削除、見るポイント、個別リンク・他のサイト、一括オープンは「詳細を開く」内にあります。候補ボタンは通常表示に残し、「この型番を調べる」リンクは詳細側に表示します。

`index.html` をブラウザーで開いてください。`styles.css`、`app.js`、`compatibility.js` を同じフォルダーに置きます。サーバー、ビルド、パッケージのインストールは不要です。現行のChrome / Edge / Firefox / Safariを想定しています。

1. 種別・型番・状態を入力します。初期表示はCPU〜ケースの8行です。クーラー、OS、その他も種別から選べます。
2. 型番の下の直リンクから各サイトを検索します。「次のサイトを開く」を押すたびに、主要3サイト（オークフリー→パソコン工房→ドスパラ）を順に1サイトずつ開きます。行ごとに進捗を表示し、4回目は最初に戻ります。型番を変更すると進捗はリセットします。残り3サイトは「他のサイト」を展開すると表示します。
3. 調べた売価を「採用価格（円）」へ入力します。状態による自動減額はありません。
4. 必要に応じて掛けを変更します。合算・目安・メモは入力に合わせて更新します。
5. 「メモをコピー」で記録します。「印刷」またはCtrl+Pでメモ全文を印刷できます。

通常は1クリックにつき1タブを開く「次のサイトを開く」を使います。PC向けの任意機能として「主要3サイトを一括で開く」も併記しています。一括オープンはブラウザのポップアップ許可が必要です。開かない場合は『次のサイトを開く』を使ってください。一括実行後は開けたタブだけを数え、ブロックされた場合はその行に案内を表示します。次の順次クリックはオークフリーから再開します。個別リンクも利用できます。

価格は0以上の整数です。半角・全角数字と、正しい3桁区切り（例：12,000）を受け付けます。空欄は「未入力」、0は「0円」として区別し、空欄は合算対象外です。入力エラーがある場合は合算・目安を「計算不可」と表示します。各価格の上限はJavaScriptの安全な整数（9,007,199,254,740,991円）、合計と丸め処理にはBigIntを使います。

掛けは0〜10、小数可。初期値の **5掛けは動作例としての仮値** で、推奨率や店舗のルールではありません。目安は「売価合算 ×（掛け ÷ 10）」の1円未満を四捨五入した値です。画面と査定メモは「5掛け（売価の50%）」の形式で変換も併記します。小数は整数比で計算し、丸め誤差を避けます。状態は誤って動作品と判断しないよう、初期値を「不明」にしています。

### キーボード操作

- Tab / Shift+Tab：項目間を移動。各行の通常表示は「種別 → 型番 → 価格 → 次のサイトを開く → 詳細を開く」の順です。詳細を開くと状態や検索リンク等にも移動できます。
- Ctrl+Enter（Macは⌘+Enter）：行を追加し、新しい行の種別へフォーカス。
- 種別・状態：標準の選択欄なので、矢印キーで変更できます。
- コピーがブラウザーや端末の制限で失敗した場合、メモを選択した状態で案内します。Ctrl+C / ⌘+C、スマホは選択メニューでコピーしてください。

### メモから取り込む・見るポイント

「メモから作る」タブの「メモから取り込む」欄に、1行ずつスペックを貼り付けて「取り込む」を押すと、既存行を残して末尾へ追加します。成功後は「パーツから入れる」へ自動で切り替わり、最初の追加行にフォーカスします。価格は未入力、状態は「不明」で作成します。取り込み自体は外部通信を行いません。

```text
GPU：RTX 5070
CPU：Core i7-12700
RAM：DDR4 16GB×2
SSD：NVMe 1TB
型番だけのメモ
```

この例はGPU・CPU・RAM・SSD・その他の5行になります。半角コロンにも対応し、グラボ／グラフィックボード、プロセッサ、メモリ、マザボ／MB、PSUは対応カテゴリへ変換します。SSD、HDD、ケース、クーラー、OS、その他も取り込めます。

入力欄には8項目のテンプレートが入っています。コロンの後ろに型番を入力してください。空行・空白だけの行・コロンの後ろが空欄の行は除外します。コロンのない行や、既存の対応表にないカテゴリの行は、行全体を「その他」の型番欄へ保持します。「テンプレートに戻す」で入力途中の内容が上書きされます。同じメモを再度取り込むと再び末尾に追加します。

各行の詳細内にある「見るポイント」は初期状態で閉じており、クリック・タップで開閉できます。種別を変更すると、そのカテゴリの確定稿へ切り替わります。取り込んだ行も、個別検索・順次オープン・合算・査定メモの対象です。

### 型番からのカテゴリ候補・PC査定のポイント

種別が「その他」の行では、型番の文字列からカテゴリ候補を提案します。メモ取り込みで「その他」になった行にも適用します。候補ボタンを押すまではカテゴリを変更せず、指定済みのカテゴリを上書きしません。

RTX／GTX／RX 7・6・5／Radeon／GeForceはGPU、Core i／Ryzen／Athlon／Celeron／PentiumはCPU、DDR3・4・5はRAMを提案します。SSD・HDDは指定キーワードとTB／GBの容量表記がある場合に提案します。80PLUSまたは3〜4桁の数値＋Wは電源の弱い候補です。複数パターンを含む場合はGPU、CPU、RAM、SSD、HDD、電源の順で最初の候補を表示します。これは文字列による補助であり、実物の判定は人が行います。

未分類で候補がない行には「この型番を調べる」を表示します。人がクリックしたときだけ型番をGoogle検索へ渡し、検索結果は取得しません。空の型番には表示しません。

「PC査定のポイント」タブの「パーツの調べ方（msinfo32／タスクマネージャー）」は折りたたみ式です。依頼で指定された確定稿を掲載しています。

### 互換性チェック

ページ上部の独立した「互換性チェック」を開き、CPU型番とマザーボード型番またはチップセット名を入力します。片方だけでも世代・ソケット・対応表の相手側を表示します。入力はパーツ行や価格計算とは独立しています。

判定データは依頼された確定稿の範囲です。Intel Core i 第6〜14世代、Ryzen 1000〜5000番台と7000番台以降の記載された形式、および指定チップセットを読み取ります。チップセットを含む `PRIME H610M-K` のような型番にも対応します。未掲載の世代・チップセット、モバイル用やX系など表のソケットを特定できない形式、複数部品を含み一意に読めない入力は推測せず「判定できませんでした」と検索リンクを表示します。検索リンクを押すまで外部通信しません。

CPUの対応判定とメモリの条件は分けます。`i5-12400F × H610` はCPU対応を「対応」と表示し、DDR4／DDR5は型番によるためメモリ互換性を別途「条件付き」と表示します。AM4のBIOS条件、400系と第11世代、A520／B550／X570と古いRyzenは型番別サポート確認が必要なため「条件付き」です。表にない型番別の例外やBIOS情報を自動取得しません。

LGA1151の世代分裂、異なるソケット、RDIMMの注意を表示します。この判定は提示表にもとづく照合であり、実際のCPUサポート・BIOS条件はメーカー資料で確認してください。印刷する査定メモの内容は変更していません。

## データと通信

- 入力データは画面を開いている間のメモリー内だけで保持します。localStorage、Cookie、外部送信、解析ツール、外部フォント、CDN、価格の自動取得は使いません。
- 再読み込み・タブを閉じる操作で入力内容は消えます。必要な記録は事前にコピー・印刷してください。
- **検索リンク・「次のサイトを開く」を自分で使った場合のみ、その行の型番が各リンク先サイトへ送られます。** 価格・状態・掛けは検索語に含めません。リンク先のアクセス履歴等は各サイト・利用端末の管理に従います。
- GitHub Pagesで開く際の静的ファイル配信の通信は発生しますが、アプリから入力データを送信する処理はありません。
- 6サイトへの検索は利用者が実際に検証した直リンクを使います。型番はURLエンコードし、価格・状態・掛けは含めません。「この型番を調べる」は別途Googleへ型番を送るリンクです。いずれも操作するまで自動送信しません。

対象はオークフリー、パソコン工房（商品検索）、ドスパラ（中古販売）、じゃんぱら、ソフマップ（中古）、メルカリの6サイトです。pasotsukuは直リンク形式未検証のため除外しました。

## GitHub Pagesで公開する

ポートフォリオ本体の `thousandplsme.github.io` には入れず、**別リポジトリ `pc-parts-total-tool`** を使用しています。別環境で公開する場合の手順は以下のとおりです。

1. GitHubで新しい公開リポジトリ `pc-parts-total-tool` を作成します。
2. `index.html`、`styles.css`、`app.js`、`compatibility.js`、`.nojekyll`、`README.md` をリポジトリのルートにアップロードし、`main` ブランチにコミットします。GitHubのファイルアップロード画面でも構いません。旧試作と検証用ファイルの公開は不要です。
3. リポジトリの **Settings → Pages → Build and deployment** で **Source: Deploy from a branch** を選びます。
4. **Branch: main / フォルダー: / (root)** を指定して **Save** します。
5. デプロイ完了後、Pagesに表示されるURLを開きます。ユーザー名が `thousandplsme` の場合、通常は `https://thousandplsme.github.io/pc-parts-total-tool/` です。
6. 更新時は同じブランチのファイルを変更してコミットします。

CSS/JSは相対パスなので、リポジトリ名がURLの途中に入るプロジェクトサイトでも動作します。手順の根拠：[GitHub公式・公開元の設定](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。2026-11-23に別リポジトリへアップロードし、main / (root) を公開元として設定しました。

## 構成と設計判断

- `index.html`：UIと常時表示の注意書き。売価合算と買取目安を画面下部の固定バーにも表示し、下部の掛け編集・詳細表示は維持します。固定バーは印刷時に非表示です。
- `styles.css`：PCでは横並び、900px以下では折り返し、540px以下では縦中心。状態を含めて入力項目を隠しません。
- `app.js`：パーツを `{ type, model, state, price }` の配列で保持します。価格の未入力は `null`。入力文字列の検証は画面側で行い、将来のCSV等に向けた専用機能は設けていません。
- 印刷は入力欄のスクロール領域を印刷せず、同じ内容のテキストを全文展開します。長い型番は折り返します。
- 既存の `pc-parts-total-tool-v0.html` はローカルに変更せず残し、公開リポジトリには含めていません。使用・公開の入口は `index.html` です。

将来構想として、価格相場グラフ、価格の自動取得とリスト表示、AIによる推奨価格が考えられますが、価格データの蓄積前なので今回は実装・ダミー表示ともに対象外です。

## 利用前の確認

店舗PCで `index.html` を開き、価格入力・コピー・印刷プレビューをご確認ください。店舗側のブラウザーポリシーや外部サイトへのアクセス制限は、このツールから変更しません。

- CPUに20,000円、GPUに30,001円、5掛け → 合算50,001円、目安25,001円。
- 型番を入力すると7リンクが出現し、消すとリンクとメモから古い型番が消える。
- 行追加・削除、Tab、Ctrl+Enter、価格0・空欄・不正値の表示。
- 幅1024px・768px・375pxで全項目が操作できる。
- コピーした内容と印刷プレビューに、全パーツ・合算・掛け・目安・注意書きが含まれる。

開発時の自動検証・未確認事項は `VALIDATION.md` に記載します。
